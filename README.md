# Homebrew tap for Spillover

[Spillover](https://github.com/Saad-ISAA/spillover) is a macOS menu bar app that gives each folder,
window and terminal its own Claude subscription.

```sh
brew install --cask saad-isaa/spillover/spillover
```

Update with `brew upgrade --cask spillover`. Before uninstalling, open Spillover and choose
**Setup → Undo all changes**, then `brew uninstall --cask spillover`.
